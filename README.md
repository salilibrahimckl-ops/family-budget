# Bro’s Fitness — large assets

- `body3d.bin.gz` — 3D muscle/skeleton model used on exercise pages. Built by `scripts/body3d/build-body3d.py`
  from **BodyParts3D © The Database Center for Life Science (DBCLS), licensed CC BY 4.0**
  (https://dbarchive.biosciencedbc.jp/en/bodyparts3d/). Changes: decimated, deep muscles removed,
  latissimus dorsi and rectus abdominis rebuilt from the body surface.
- `three.min.js` — three.js r128 (MIT licence, © three.js authors), offline fallback copy.
